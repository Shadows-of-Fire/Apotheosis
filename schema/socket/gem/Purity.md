# Description
Purity represents a fixed set of gem tiers. Gems are expected to have increasingly powerful stats with each purity level.

# Schema
Purity is represented as a string literal. It may take one of the following values:

1. `"cracked"` - Lowest tier, represented with a gray color (0x808080)
2. `"chipped"` - Represented with a green color (0x33FF33)
3. `"flawed"` - Represented with a blue color (0x5555FF)
4. `"normal"` - Represented with a purple color (0xBB00BB)
5. `"flawless"` - Represented with an orange color (0xED7014)
6. `"perfect"` - Highest tier, represented with a rainbow gradient color
